# investment-articles

> Investment articles I read and like. —— 我读过并喜欢的投资文章。

## 关于本仓库

收集整理投资相关的 Markdown 文章，包括：

- 基金经理路演 / 交流纪要整理稿
- 投资方法论与体系梳理
- 行业与公司研究
- 投资相关读书笔记

全部文章以 Markdown 格式沉淀，便于检索、引用与二次编辑。

## 目录结构

```text
investment-articles/
├── README.md                    # 本文件：仓库说明与文章索引
└── articles/                    # 所有文章（Markdown）
    └── YYYY-MM-DD-文章标题.md
```

## 命名与写作规范

1. 所有文章统一放在 `articles/` 目录下；
2. 文件名以日期开头：`YYYY-MM-DD-文章标题.md`，保证按时间自然排序；
3. 每篇文首附 300–500 字概要，方便快速筛选；
4. 纪要类文章保留原始口径标注（如「管理人口径」「数字待核」），引用数据前请核实；
5. 引用他人观点时注明来源与时间。
